# Переключатель режима платформы: B2C / B2B / B2C + B2B

## Что уже есть в проекте (проверено)

- B2C-маршруты: `/`, `/analyze`, `/results`, `/tariffs`, `/pay/:orderId`, `/my-reports`, `/login`, `/register`.
- B2B-маршруты: `/partner/register`, `/partner/login`, `/partner/dashboard`, `/c/:slug`, `/c/:slug/analyze`, `/c/:slug/results`.
- Меню: `DesktopNav` (Анализ, Отчёты, Тарифы + вход/регистрация) и `BottomNavigation` (Главная, Анализ, Отчёты, Тарифы) — сейчас там только B2C-пункты; публичных ссылок на партнёрский раздел в меню нет (вход по прямому URL).
- Админка `/admin` — вкладки: Заказы, Настройки оплаты, Реклама, Рефералы, Статистика, Для партнёров.
- Уже есть таблица настроек `payment_settings` (key/value, чтение — только админ, плюс белый список публичных ключей через функцию `get_public_payment_settings`).

Ничего из перечисленного не удаляется и не переписывается.

## Как будет храниться режим

Отдельная новая таблица не нужна: используем существующий подход «ключ-значение», но заводим отдельную таблицу `platform_settings`, чтобы не смешивать платёжные настройки с конфигурацией платформы (в `payment_settings` политика чтения ограничена админом, а режим нужен всем посетителям).

- Таблица `platform_settings(key text primary key, value text, updated_at)`.
- Строка по умолчанию: `platform_mode = 'both'` (обратная совместимость — поведение сайта не меняется).
- Доступ: чтение — всем (anon/authenticated), запись — только админам (`has_role(auth.uid(),'admin')`), плюс GRANT'ы.

## Что добавляется

1. **Хук `usePlatformMode`** (React Query, как в проекте) — читает `platform_mode`, кэширует, значение по умолчанию `both` при любой ошибке/загрузке. Никаких блокировок до загрузки настройки.
2. **Блок в админке** — новая вкладка «Настройки платформы» с RadioGroup из трёх вариантов и описаниями (B2C / B2B / B2C + B2B), кнопка сохранения, тост «Режим работы платформы изменён», инвалидация кэша.
3. **Компонент-охранник `ModeGuard`** — оборачивает маршруты в `App.tsx`. Если маршрут недоступен в текущем режиме:
   - админ — пропускается всегда;
   - обычный пользователь — редирект на доступную стартовую страницу либо страница «Раздел недоступен в текущем режиме» (в стиле проекта).
4. **Условное меню** — `DesktopNav` и `BottomNavigation` скрывают B2C-пункты в режиме B2B и показывают партнёрские пункты (Кабинет клиники / Вход для клиник) в режимах B2B и both.
5. **Главная страница** — в режиме B2B B2C-блоки (загрузка анализа, пользовательские тарифы, реферальная плашка, бесплатная расшифровка) скрываются, показывается блок для клиник со ссылками на регистрацию/вход партнёра. В режимах B2C и both — как сейчас.

## Карта доступности маршрутов

```text
режим b2c   : B2C-маршруты — да ; /partner/*, /c/* — нет (кроме админа)
режим b2b   : /partner/*, /c/* — да ; /analyze, /tariffs, /pay, /my-reports, /results — нет
режим both  : всё доступно (текущее поведение)
```

`/`, `/login`, `/register`, `/admin` доступны всегда.

## Безопасность

- Скрытие в UI — не единственная защита: `ModeGuard` перехватывает прямой ввод URL.
- Полное серверное отключение бизнес-логики (edge functions) в объём не входит: режим — это конфигурация витрины, а не отзыв прав. Если нужно жёстко запрещать создание заказов/расшифровок на сервере в «чужом» режиме — скажите, добавлю проверку режима в соответствующие edge-функции отдельным шагом.
- Админ сохраняет полный доступ ко всем вкладкам админки в любом режиме.

## Технические детали

- Миграция: `CREATE TABLE public.platform_settings` + GRANT (`SELECT` для anon/authenticated, `ALL` для service_role) + RLS + политики (публичное чтение, запись админам) + вставка `platform_mode = 'both'`.
- Новые файлы: `src/hooks/usePlatformMode.ts`, `src/components/PlatformModeAdmin.tsx`, `src/components/ModeGuard.tsx`, `src/pages/ModeUnavailable.tsx` (или инлайн-блок).
- Изменяемые файлы (точечно): `src/App.tsx` (обёртки маршрутов), `src/pages/Admin.tsx` (новая вкладка), `src/components/DesktopNav.tsx`, `src/components/BottomNavigation.tsx`, `src/pages/Home.tsx` (условные блоки).
- Ничего не удаляется: страницы, таблицы, RPC, edge-функции, тарифы, PDF, Telegram и Gemini-интеграции остаются без изменений.

## Проверка

Прогоню через браузер три сценария (b2c, b2b, both): доступность меню, редиректы при ручном вводе URL, сохранение режима после перезагрузки, полный доступ админа.
