

# Комплексная проверка и исправление приложения

## Проблема 1: Кнопки "Загрузить" и "Камера" не работают на мобильном

**Причина:** Кнопки используют `<Button>` (компонент с `type="button"`), который программно вызывает `fileInputRef.current?.click()`. На мобильных браузерах это работает, но есть проблема с кнопкой "Камера" -- атрибут `capture` устанавливается и тут же удаляется (`setAttribute` -> `click()` -> `removeAttribute`), что вызывает race condition. Кроме того, на некоторых мобильных браузерах `click()` на скрытый input может блокироваться.

**Решение:** Заменить подход с одним скрытым input на два отдельных: один для загрузки файла, второй с атрибутом `capture="environment"` для камеры. Это устраняет race condition и гарантирует корректную работу на всех мобильных браузерах.

## Проблема 2: Привязка к Telegram-боту

**Результат проверки:** Приложение **не привязано** напрямую к Telegram-боту для основной работы. Есть:
- Edge-функция `telegram-auth` -- используется только если пользователь заходит через Telegram Mini App, но не вызывается в веб-версии
- Ссылки на Telegram-канал `@medgid_mo` (не на бота) -- это просто внешние ссылки
- В `Analyze.tsx` передается `telegramId: null` -- Telegram не используется

Приложение полностью работает как самостоятельная веб-версия. Удаление функции `telegram-auth` не требуется -- она просто не вызывается при работе через веб. Можно убрать её из конфигурации если нужно полностью отвязать.

## Проблема 3: Экспорт и скачивание на смартфоне

**Результат проверки:** Логика экспорта уже исправлена в предыдущей итерации -- используется Web Share API на мобильных с fallback на `window.open`. Код выглядит корректно.

### Файл: `src/pages/Analyze.tsx`

Заменить один скрытый `<input type="file">` на два:
1. `<input type="file" accept="image/*">` -- для кнопки "Загрузить"
2. `<input type="file" accept="image/*" capture="environment">` -- для кнопки "Камера"

Каждая кнопка будет вызывать `click()` на свой input, без динамической смены атрибутов.
