
# План: Система тарифных планов для партнёров

## Обзор задачи

Реализовать систему из трёх тарифных планов для клиник-партнёров с учётом использованных расшифровок:

| План | Расшифровок | Цена |
|------|-------------|------|
| Стандарт | 1,000 | 30,000 ₽ |
| Бизнес | 3,000 | 50,000 ₽ |
| Премиум | 10,000 | 80,000 ₽ |

---

## Архитектура решения

### Новая таблица: `partner_subscriptions`

Хранит текущую подписку каждого партнёра:

```text
partner_subscriptions
├── id (uuid)
├── partner_id (uuid → partners.id)
├── plan_type (enum: standard, business, premium)
├── analyses_limit (int) — лимит расшифровок
├── analyses_used (int) — использовано расшифровок
├── price (int) — цена в рублях
├── activated_at (timestamp) — когда активирован
├── activated_by (uuid) — кем активирован (админ)
├── is_active (boolean) — активна ли подписка
├── created_at (timestamp)
```

### Новая таблица: `subscription_history`

История всех активаций (для отчётности):

```text
subscription_history
├── id (uuid)
├── partner_id (uuid)
├── plan_type (enum)
├── analyses_limit (int)
├── price (int)
├── action (enum: activated, expired, renewed)
├── created_at (timestamp)
├── admin_id (uuid) — кто активировал
```

---

## Логика работы

### 1. Проверка лимита при расшифровке

В edge-функции `analyze-medical-photo` добавляется проверка:

```text
1. Если partner_id указан:
   a. Получить текущую подписку партнёра
   b. Проверить: analyses_used < analyses_limit?
   c. Если НЕТ → вернуть ошибку "Лимит расшифровок исчерпан"
   d. Если ДА → выполнить анализ и увеличить analyses_used на 1
```

### 2. Активация тарифа (через админку)

Пока реализуем ручную активацию администратором:

```text
1. Админ выбирает партнёра
2. Выбирает тарифный план
3. Система создаёт/обновляет запись в partner_subscriptions
4. Записывает событие в subscription_history
```

## Безопасность (RLS-политики)

```text
partner_subscriptions:
├── SELECT: админы видят все, партнёры — только свои
├── INSERT: только админы
├── UPDATE: только админы

subscription_history:
├── SELECT: админы видят все, партнёры — только свои
├── INSERT: только система (через SECURITY DEFINER функции)
```

---

## Поведение при исчерпании лимита

Когда `analyses_used >= analyses_limit`:
- Пользователь клиники получает сообщение: "Лимит расшифровок вашей клиники исчерпан. Обратитесь к администратору клиники."
- Партнёр в дашборде видит красный индикатор
- Админ видит партнёра как "Лимит исчерпан" в списке
