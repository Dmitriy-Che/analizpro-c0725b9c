
# План: Инфографика в результатах анализов

## Обзор задачи

Превратить текстовые результаты анализов в красивую визуальную инфографику с диаграммами и возможностью поделиться документом в виде изображения или PDF.

## Что получит пользователь

После расшифровки пациент увидит:
- Визуальные карточки для каждого показателя с отклонением
- Цветовую индикацию (зелёный - норма, жёлтый - внимание, красный - критично)
- Мини-диаграммы показывающие где значение относительно нормы
- Круговую диаграмму общего статуса
- Кнопку "Скачать отчёт" - сохранит красивый PDF/PNG с диаграммами

---

## Архитектура решения

### Изменение 1: Структурированный ответ от ИИ

Сейчас ИИ возвращает обычный текст. Нужно изменить промпт чтобы ИИ возвращал **JSON с данными**:

```text
{
  "overall_status": "warning",
  "summary": "Обнаружено 2 показателя с отклонениями",
  "indicators": [
    {
      "name": "Гемоглобин",
      "value": 95,
      "unit": "г/л",
      "reference_min": 120,
      "reference_max": 160,
      "status": "low",
      "explanation": "Гемоглобин переносит кислород...",
      "recommendation": "Обратитесь к терапевту...",
      "specialist": "Терапевт, гематолог"
    }
  ],
  "general_recommendations": "Рекомендуется повторный анализ через 2 недели",
  "follow_up": "Через 14 дней"
}
```

### Изменение 3: Генерация PDF/изображения

Использовать `html2canvas` для создания скриншота блока результатов и `jsPDF` для генерации PDF-документа.

Документ будет содержать:
- Шапку с логотипом АнализПро
- Дату и данные пациента (возраст, пол)
- Все диаграммы и визуализации
- Пояснения к каждому показателю
- Рекомендации

## Технические шаги

### Шаг 1: Установка зависимостей

Добавить библиотеки:
- `html2canvas` - для создания скриншота HTML-элемента
- `jspdf` - для генерации PDF

### Шаг 2: Изменение промпта ИИ

В `supabase/functions/analyze-medical-photo/index.ts` изменить system prompt для возврата структурированного JSON вместо текста.

Добавить парсинг JSON в ответе и fallback на текстовый формат для обратной совместимости.

### Шаг 3: Создание компонентов визуализации

Новые файлы:
- `src/components/results/IndicatorCard.tsx` - карточка одного показателя с мини-графиком
- `src/components/results/StatusChart.tsx` - круговая диаграмма общего статуса
- `src/components/results/ValueBar.tsx` - полоса визуализации значения относительно нормы
- `src/components/results/AnalysisReport.tsx` - полный отчёт для экспорта

### Шаг 4: Обновление страницы Results

В `src/pages/Results.tsx` и `src/pages/clinic/Results.tsx`:
1. Парсить JSON-ответ от ИИ
2. Отображать визуальные компоненты вместо текста
3. Добавить кнопки экспорта в PDF/PNG

### Шаг 5: Функция экспорта

Создать `src/utils/exportReport.ts`:
- `exportAsPNG(elementId)` - скачивание как изображение
- `exportAsPDF(elementId, patientData)` - скачивание как PDF-документ
