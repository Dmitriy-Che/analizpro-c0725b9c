

# Упрощение кнопок экспорта результатов

## Что меняем

1. **Убираем "Скачать PNG"** из диалога "Поделиться" в обоих файлах (`Results.tsx` и `clinic/Results.tsx`)
2. **Убираем кнопку "Скачать PDF"** из основного экрана -- на мобильных она вызывает ошибку, а функция дублируется через "Поделиться" -> "Отправить PDF"
3. Вместо двух кнопок ("Скачать PDF" + "Поделиться") оставляем **одну кнопку "Поделиться"** на полную ширину

## Итоговый вид

**Основной экран результатов:**
- Одна кнопка: **"Поделиться"**

**Диалог "Поделиться":**
- Отправить PDF
- Отправить как изображение
- Скопировать текст

(PNG убран, отдельная кнопка PDF убрана)

## Затрагиваемые файлы

| Файл | Изменение |
|------|-----------|
| `src/pages/Results.tsx` | Убрать кнопку "Скачать PDF", убрать "Скачать PNG" из диалога, удалить неиспользуемые функции/импорты |
| `src/pages/clinic/Results.tsx` | Аналогичные изменения |

## Технические детали

- Удалить `handleExportPDF`, `handleExportPNG` функции и импорт `exportAsPDF`, `exportAsPNG`
- Убрать неиспользуемые иконки из импортов (`Download`)
- Заменить `div` с двумя кнопками на одну кнопку "Поделиться"
- Удалить блок "Скачать PNG" из диалога шаринга
